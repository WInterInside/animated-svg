# Animated SVG

Небольшая коллекция самостоятельных SVG-фигур для веб-интерфейсов. Каждый файл можно использовать через обычный `<img>` — стили и анимация находятся внутри SVG.

## Фигуры

| Файл | Идея |
| --- | --- |
| `animate-shape.svg` | Пластичная форма |
| `orbit.svg` | Две вращающиеся орбиты |
| `prism.svg` | Движущийся кристалл |
| `pulse.svg` | Расходящиеся кольца |
| `wave.svg` | Три мягкие волны |
| `bloom.svg` | Вращающийся цветок |
| `helix.svg` | Две переплетённые линии |
| `lattice.svg` | Пульсирующая решётка |

В репозитории также сохранены исходные `gem.svg`, `large-gem.svg` и `volume-high.svg`.

```html
<img src="orbit.svg" alt="" width="100" height="100">
```

У семи новых фигур анимация останавливается, если в системе включено уменьшение движения (`prefers-reduced-motion`).
